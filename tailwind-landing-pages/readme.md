# 🎨 Tailwind Landing Pages

A collection of **responsive landing pages** built using **Tailwind CSS** as part of my UI and layout practice.

This folder focuses on exploring **utility-first design**, rapid prototyping, and clean responsive layouts — all without JavaScript.

---

## 📌 Purpose of This Folder

The goal of these projects is to:

- Understand Tailwind’s utility-first workflow
- Build layouts faster compared to vanilla CSS
- Practice responsive design patterns
- Experiment with spacing, typography, and visual balance
- Compare Tailwind CSS with custom CSS approaches used elsewhere in this repository

These are **practice & learning projects**, intentionally kept simple and focused.

---

## 🛠️ Tech Stack

- **HTML5**
- **Tailwind CSS (via npm)**
- **Responsive Design**
- **Static Hosting (GitHub Pages / Netlify)**
